# Agent skills

Project skills live in `.agents/skills/` (Cursor discovers this path automatically). The catalog and update command are in `.agents/README.md`.

Default feature workflow for this repo: **grill → spec → tickets → TDD implement → review**.

Use `ask-matt` when unsure which Matt Pocock skill to run. Use `using-agent-skills` for Addy Osmani's lifecycle map. Use `using-superpowers` for Superpowers branch/review/verification moves.

### Issue tracker

GitHub Issues via `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default roles: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` at the repo root and `docs/adr/`. See `docs/agents/domain.md`. If those files are missing, proceed silently.
